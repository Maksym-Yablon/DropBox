# Drop Box - Godot v4.4.1 Version

Повна конвертація гри з Python/Pygame на Godot v4.4.1.

## Структура проекту

### Основні скрипти (GDScript)
- `Constants.gd` - Автозавантаження з усіма константами гри
- `CashManager.gd` - Автозавантаження для управління валютою
- `SoundManager.gd` - Автозавантаження для управління звуками
- `Piece.gd` - Ресурс для фігур з текстурами котів
- `Grid.gd` - Node2D для ігрової сітки 8x8
- `PieceBox.gd` - Node2D для контейнера фігур з drag & drop
- `Shop.gd` - Node2D для внутрішньоігрового магазину
- `GameMain.gd` - Головна сцена гри
- `RecordsManager.gd` - Ресурс для управління рекордами
- `SaveManager.gd` - Ресурс для збереження/завантаження гри

### Сцени
- `GameMain.tscn` - Головна ігрова сцена

### Налаштування проекту
- `project.godot` - Налаштування Godot проекту з автозавантаженням

## Ключові особливості конвертації

### 1. Автозавантаження (Singletons)
- `Constants` - Глобальні константи, розміри, кольори
- `CashManager` - Управління валютою catcoin
- `SoundManager` - Система звуків з оптимізацією

### 2. Ресурси (Resources)
- `Piece` - Фігури з підтримкою спрайтів котів
- `RecordsManager` - Рекорди гри
- `SaveManager` - Збереження прогресу

### 3. Node2D компоненти
- `Grid` - Сітка з візуальним рендерингом
- `PieceBox` - Контейнер фігур з drag & drop
- `Shop` - Магазин з інтерактивним UI

### 4. Візуальний стиль
- М'які заокруглені кути
- Темна тема з приглушеними кольорами
- Спрайти котів для блоків фігур
- Сучасний мобільний дизайн

### 5. Геймплей
- Drag & drop фігур
- Автоматичне очищення ліній
- Система комбо
- Внутрішньоігрова валюта
- Магазин з покупками
- Збереження прогресу

## Налаштування для роботи

### 1. Структура папок assets
```
assets/
├── sprites/
│   └── cats/
│       ├── blue_block_cat.png
│       ├── mind_block_cat.png
│       ├── orange_block_cat.png
│       ├── pink_block_cat.png
│       ├── purple_block_cat.png
│       ├── red_block_cat.png
│       ├── white_block_cat.png
│       └── yelow_block_cat.png
├── sounds/
│   ├── effects/
│   └── music/
└── fonts/
    └── default.ttf
```

### 2. Автозавантаження в project.godot
```ini
[autoload]
Constants="*res://Constants.gd"
CashManager="*res://CashManager.gd"
SoundManager="*res://SoundManager.gd"
```

### 3. Запуск гри
1. Відкрий проект в Godot 4.4.1
2. Встанови головну сцену: `GameMain.tscn`
3. Додай необхідні ресурси (спрайти, звуки, шрифти)
4. Запусти проект
